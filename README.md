# Libyan-Sentiment-Analysis
Sentiment Analysis for Libyan Dialect Tweets using Machine Learning and Custom Lexicon
This repository contains the dataset, custom lexicon, and preprocessing/classification code for the Master's thesis on Libyan dialect sentiment analysis.
## Contents:
- `libyan_lexicon.csv`: Custom Sentiment Lexicon for Libyan Dialect.
- `preprocessing.py`: Text cleaning, normalization, and negation handling code.
- `model_training.py`: Machine Learning classification models (SVM, Naive Bayes, etc.).
